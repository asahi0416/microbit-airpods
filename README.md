# micro:bit v1 - AirPods 近接ペアリング通知送信（完全ランダム版）

BBC micro:bit v1 (Nordic nRF51822) を使用して、Aボタンを押したときに iPhone などの iOS 端末に向けて「新しいAirPods」の近接ペアリング通知（セットアップポップアップ）をBLEで送信するプロジェクトです。

---

## 特徴

1. **クールダウンなし（即時送信＆連続送信対応）**
   - Aボタンを押すと待ち時間ゼロで即座に送信を開始します。
   - 1回押すと1.5秒間送信し、ボタンを長押ししている間は連続で送信し続けます。
2. **AirPodsモデル・MACアドレス・個体識別子の完全ランダム化**
   - ハードウェア乱数生成器（`NRF_RNG`）により、送信ごとに以下をすべてランダム生成します：
     - **送信元BLE MACアドレス（6バイト）**
     - **AirPodsモデルID（全6種からランダム選択）**:
       - AirPods（第1世代 / 第2世代 / 第3世代）
       - AirPods Pro（第1世代 / 第2世代）
       - AirPods Max
     - **バッテリー残量および個体識別ハッシュ領域（16バイト）**
   - 長押し中は0.5秒ごとに別の新しいAirPods個体へ自動的に切り替わります。
3. **5×5 全25個LEDマトリクスによる高速点滅表示**
   - 起動時に全LEDが2回点滅して準備完了を知らせます。
   - Aボタンを押して送信している間は、5×5の全25個のLEDがピカピカと高速点滅するため、電波送信中であることが一目で分かります。

---

## 使い方

1. iPhone の **Bluetoothをオン** にし、**画面を点灯・ロック解除** します。
2. micro:bit の **Aボタン** を押します（長押しで次々に別モデルを連続送信）。
3. 5×5の全LEDが点滅し、iPhone の画面下部に AirPods の接続ポップアップが表示されます。
