# micro:bit v1 - AirPods 近接ペアリング通知送信

BBC micro:bit v1 (Nordic nRF51822) を使用して、Aボタンを押したときに iPhone などの iOS 端末に向けて「新しいAirPods」の近接ペアリング通知（セットアップポップアップ）をBLEで送信するプロジェクトです。

---

## 特徴

1. **ベアメタル無線制御（SoftDevice不要）**
   - nRF51822 の `NRF_RADIO` ハードウェアレジスタを直接制御し、BLEアドバタイジングチャネル（Ch 37, 38, 39）へ生パケットを送出します。
   - 面倒な SoftDevice (S110) の別途インストール・ブートローダ書き込みが不要です。
2. **動的ランダムMACアドレス生成（キャッシュ・スパム判定回避）**
   - Aボタンを押すたびにハードウェア乱数生成器（`NRF_RNG`）で新しいランダムMACアドレスを生成して送信するため、iOS側で同一デバイスの連続スパムとして無視されるのを防ぎます。
3. **レート制限防止クールダウン**
   - 1回のAボタン押下で **約2.5秒間** アドバタイズを送信して自動停止し、その後 **3秒間のクールダウン** を設けています。
4. **視覚フィードバック**
   - 送信中は micro:bit 本体の左上LEDが点灯し、送信完了で消灯します。

---

## 使い方（テスト方法）

1. iPhone の **Bluetoothをオン** にし、**画面を点灯・ロック解除** します。
2. micro:bit を iPhone のすぐ近くに置きます。
3. micro:bit の **Aボタン** を押します。
4. 左上のLEDが約2.5秒間点灯し、iPhone の画面下部に AirPods の接続ポップアップが表示されます。
