# micro:bit v1 - AirPods 近接ペアリング通知送信

教育用マイコンボード **BBC micro:bit v1** を使って、Aボタンを押すと近くの iPhone に「新しいAirPods」のセットアップ通知（接続ポップアップ）を表示させるプロジェクトです。

---

## 🚀 一番簡単な使い方（開発環境・インストール一切不要！）

Arduino IDE や専門的な開発ツールのインストールは**不要**です。  
Windows / Mac / Chromebook のどれでも、**ファイルを入れてドラッグ＆ドロップするだけ**で動きます。

### 3ステップで完了！

1. **ファイルをダウンロードする**:
   - このリポジトリにある [**`microbit-airpods.hex`**](microbit-airpods.hex) をクリックし、右上の「Download raw file」ボタンからダウンロードします。
2. **micro:bit をパソコンに接続する**:
   - USBケーブルで micro:bit をパソコンに繋ぐと、USBメモリのように **`MICROBIT`** というドライブが表示されます。
3. **ファイルを放り込む（書き込み完了！）**:
   - ダウンロードした `microbit-airpods.hex` を **`MICROBIT` ドライブにドラッグ＆ドロップ** します。
   - micro:bit 裏面の黄色いランプがチカチカ点滅し、点滅が終われば準備完了です！

> [!TIP]
> **元のmicro:bit（MakeCode）に戻したいときは？**  
> いつも通り [MakeCode](https://makecode.microbit.org/) でプログラムを作って `MICROBIT` ドライブに保存するだけで、いつでも一瞬で元の教育用micro:bitに戻せます。

---

## 📱 テスト方法

1. iPhone の **Bluetoothをオン** にし、**画面を点灯・ロック解除** してホーム画面を開いておきます。
2. micro:bit を iPhone の近く（5〜10cm程度）に近づけます。
   - ※micro:bit 裏面左上のアンテナ部分を手で覆わないように持つと電波がよく届きます。
3. micro:bit の **Aボタン** を押します。
4. micro:bit の **5×5全LEDがピカピカ点滅** し、iPhone の画面下部に AirPods のセットアップポップアップが表示されます！

---

## ✨ 主な機能と特徴

* **全6種類のAirPodsモデルを毎回ランダム送信**:
  - Aボタンを押すたびに、内蔵ハードウェア乱数生成器（`NRF_RNG`）で以下のモデルから自動でランダム選択されます：
    - AirPods（第1世代 / 第2世代 / 第3世代）
    - AirPods Pro（第1世代 / 第2世代）
    - AirPods Max
* **送信元MACアドレスの自動ランダム生成**:
  - 送信ごとに異なるBLE MACアドレスを動的生成するため、iOS側の「同一端末からの連続スパム無視」に引っかかりません。
* **クールダウンなし（即時送信・連続送信対応）**:
  - ボタンを押せば待ち時間ゼロで即座に送信。長押ししている間は連続送信されます。
* **ベアメタル無線制御（SoftDevice不要）**:
  - nRF51822 の無線レジスタ（`NRF_RADIO`）を直接制御し、余計なBluetoothスタックを挟まずに軽量・超高速でパケットを送出します。
* **視覚フィードバック**:
  - 送信中は本体の5×5全25個LEDが激しく点滅するため、電波が出ていることが一目で分かります。

## 🛠️ ソースコードから自分でビルドしたい場合（開発者向け）

自分でコードを改造したりビルドしたい場合は、以下の手順で行えます。

1. このリポジトリをクローンまたはダウンロードします。
2. スケッチファイル: `microbit_airpods/microbit_airpods.ino`
3. [`flash.bat`](flash.bat) をダブルクリックするだけで、自動的にコンパイルと micro:bit への書き込みが実行されます。

## ⚠️ ご注意・マナー
